Как опубликовать (бесплатно, 2 минуты):
1. Откройте https://app.netlify.com/drop (или Cloudflare Pages / GitHub Pages).
2. Перетащите на страницу папку с этими файлами (распакованный архив).
3. Откройте полученный https-адрес в Chrome на Android.
4. Меню ⋮ -> "Установить приложение" (или "Добавить на главный экран").
Нужен именно https: на обычном http установка и офлайн-режим не работают.
